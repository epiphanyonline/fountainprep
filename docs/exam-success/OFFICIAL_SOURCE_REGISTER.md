These official resources support syllabus alignment and academic analysis. Public
availability **does not** establish a licence to republish questions in a paid
Fountain Prep product. No questions have been copied from these pages.

verified before authoring examination-specific paper blueprints.

## Required content ingestion process

1. **Source investigation:** log board, exact source, syllabus year, skills,
   difficulty and style, official status, and last date checked.
2. **Rights verification:** for actual historic questions, require documented
   permission covering commercial online reproduction, edits, audio/media
   and monetisation, with scope/expiry. Never assume a downloadable PDF
   can be imported verbatim. Source-linking itself is not reuse permission.
3. **Independent authoring:** produce genuinely new questions from
   curriculum objectives and assessment patterns, not superficial edits
   of individual protected past questions; record authorship attestation.
4. **Two-stage review:** academic correctness, distractor quality, clarity,
   syllabus match, difficulty, originality and provenance checks.
5. **Publishing:** release only independently reviewed, approved versions;
   freeze versions for started attempts and weekend events.
6. **Maintenance:** update outdated syllabus mappings, retire poor-quality
   questions and measure weak-item performance as usage grows.

## Important truth-in-labelling

- 'Official past examination question' **only** if verified original and
  its reproduction rights are cleared.
- 'Original JAMB-style question' or equivalent when Fountain Prep authors
  the question and its reviewed mapping is valid.
- The current admin page contains only two **fictional samples** and a
  preview-only approval flow, not live exam inventory.
- A large and representative question bank is a content-production objective,
  not an existing accomplishment.

This register is reference data for academic research only. Before launch,
validate each source against the official 2027 (or applicable) examination
year publications and audit the permissions independently.
