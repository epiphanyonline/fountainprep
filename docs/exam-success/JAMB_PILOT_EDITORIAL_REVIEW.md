- Mathematics: current public IBASS Mathematics syllabus topic groups. Source reference is broad;
  item-level syllabus-objective confirmation by a curriculum specialist remains outstanding.
- These drafts are tagged `syllabusYear: 2026` provisionally. **Do not relabel as verified
  JAMB 2027 syllabus questions without checking the actual 2027 publication.**

  question banks. An originality and academic review is required before use.

## Review workflow

1. Subject specialist checks current IBASS syllabus version, question/section appropriateness,
   topic code, difficulty, distractors, unambiguous key, explanation and language style.
2. Rights/editorial reviewer checks independent authorship and similarity against any
   legitimately acquired licensed historical question corpus.
3. Fix incorrect or ambiguous items in a NEW revision (don't alter a paper already used).
4. A reviewer independent of the author records approval.
5. A separately authorised admin publishes a verified revision for eligible paper assembly.
6. Before a paid weekend mock, validate the **entire** assembled paper, exam blueprint,
   timing and marks, then freeze that revision.
