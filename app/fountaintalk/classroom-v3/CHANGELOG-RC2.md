# Changelog — FountainTalk 1.0 RC2

## Added
- Production runtime telemetry contracts and buffered telemetry sink.
- Scene asset collection and configurable lookahead prefetching.
- Accessibility preference normalization for captions, reduced motion, high contrast and font scaling.
- Release-readiness assessment and Studio publishing gate.
- RC2 production-readiness documentation and tests.

## Compatibility
- Existing public APIs remain available.
- New production capabilities are opt-in.
- Existing journey rendering is unchanged unless the host integrates the new modules.
